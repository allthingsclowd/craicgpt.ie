Use these prompts to generate the HashiCorp Configuration Language (HCL) code for the core AWS infrastructure.

1. S3 Website Bucket 
Generate Terraform HCL for an S3 bucket named `craicgpt-website-assets` to host static files. Configure it for private access via CloudFront using OAC, with versioning and SSE-S3 encryption.
2. CloudFront Distribution 
Create Terraform HCL for a CloudFront distribution using the S3 website bucket as an OAC origin. Associate an ACM certificate ARN, add custom domains, enforce HTTPS, and set cache behaviors for static assets (long TTL) and daily content at `/content/*` (24hr TTL).
3. Orchestrator Lambda 
Generate Terraform HCL for an AWS Lambda function `ContentOrchestratorLambda` using the `terraform-aws-modules/lambda/aws` module. Set runtime to `nodejs18.x`, define source path, and pass S3 bucket name and Secret ARNs as environment variables. The IAM role should allow logging, getting specific secrets, and putting objects to the content S3 bucket.
4. EventBridge Scheduler 
Create Terraform HCL for an EventBridge Scheduler rule to trigger the `ContentOrchestratorLambda` daily at 01:00 UTC using a cron expression.

Use these prompts to generate the static files for the website's Minimum Viable Product (MVP).

1. HTML Structure 
Create the basic HTML structure (`index.html`) for the CraicGPT.ie front page. The structure should be semantic and include placeholder divs with unique IDs for all dynamic newspaper elements: banner, date, bio, main article (title, image, text), comparison article (title, image, text), LLM story, joke, and fake advertisements.
2. CSS Styling 
Provide CSS code (`style.css`) to style the `index.html` into a multi-column layout reminiscent of a traditional broadsheet newspaper. Utilize CSS Grid for the main page structure. Define styles for a clear visual hierarchy using classic newspaper fonts. Ensure the layout is responsive.
3. JavaScript Logic 
Write JavaScript code (`main.js`). On window load, it should get the current date, construct a URL to the daily content JSON file (e.g., `.../content/YYYY/MM/DD/todays_paper.json`), and use the `fetch` API. On success, parse the JSON and update the `innerHTML` of the placeholder elements with the fetched data. Include error handling.

Use these prompts to generate the serverless functions that will power the daily content generation.

1. Lambda LLM Handler 
Provide a TypeScript AWS Lambda handler (`llmHandler.ts`). It should accept a `prompt` in the event payload, retrieve an LLM API key from Secrets Manager (using an environment variable for the Secret's ARN), make a POST request to a hypothetical LLM API, parse the response, and return the generated text. Include robust error handling and logging.
2. Lambda ImageGen Handler 
Provide a TypeScript AWS Lambda handler (`imageGenHandler.ts`). It should accept a `prompt` in the event, retrieve an ImageGen API key from Secrets Manager, and post to an ImageGen API. If the API returns image binary data, the function must upload it to the S3 content bucket (name from env var) under a unique, date-stamped key and return the S3 object URL. If the API returns a URL, return that directly.
3. Branding Image Prompt 
Generate an image prompt for a model like DALL-E 3 to create a logo for 'CraicGPT.ie'. It should fuse Irish 'craic' (fun, wit) with AI/tech elements (neural patterns, circuits). Incorporate a newspaper or comic book motif (speech bubbles, newsprint texture). The style should be friendly and modern, using a color palette of greens with vibrant accents.
